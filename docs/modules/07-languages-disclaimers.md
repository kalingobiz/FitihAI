# Module 07 — Languages and Disclaimers

## 1. Purpose
Serve users in the language they actually speak, and guarantee that every AI
output carries the notice that it is legal information, not legal advice.

## 2. Scope
**In scope:** the list of supported languages, language codes and normalisation,
the disclaimer text in each language, shared UI strings (bot and API), and the
instruction that tells the AI which language to write in.
**Out of scope:** translating law texts, and the web-only labels (these live in
`web/app.js`, module 09).

## 3. Files
| File | Role |
|---|---|
| `fitihai/i18n.py` | `LANGUAGES`, `LANGUAGE_NAMES_EN`, `DISCLAIMER`, `UI`, `normalize_language`, `t`, `disclaimer` |
| `fitihai/prompts.py` | `language_instruction(language_name)` |
| `web/app.js` | `LABELS`: web-only interface strings in 4 languages |

## 4. Interfaces
| Item | Description |
|---|---|
| Codes | `am` Amharic (አማርኛ), `om` Afaan Oromo, `ti` Tigrinya (ትግርኛ), `en` English |
| `normalize_language(x)` | Lower-cases, keeps the first 2 letters, and falls back to `am` if unknown |
| `disclaimer(lang)` | The notice for that language (English if missing) |
| `t(key, lang)` | UI string lookup, e.g. `welcome`, `choose_language`, `working`, `new_session`, `quota_exceeded`, `voice_unsupported`, `error`, `sources`, `deadlines`, `ask_lawyer` |
| `GET /api/meta` | Returns languages, UI strings and disclaimers to the web client |

## 5. Design and flow
- **Default language is Amharic.** It is the most widely read language in the target
  area and the authoritative language of federal law.
- **Output language is chosen by the user, not detected.** Amharic and Tigrinya share
  the Ge'ez script and are easy to confuse. Users also often write in one language
  but want the answer in another.
- The pipeline adds `"Write every user-facing field … in <Language>. Keep law titles
  and article numbers recognisable."` to each AI request.
- **The disclaimer is appended by code, not generated by the AI.** It therefore
  appears on 100% of responses, in the correct wording, even if the model misbehaves.
  The prompt tells the model *not* to write its own disclaimer, to avoid duplicates.

**English source text of the disclaimer**
> This analysis is AI-generated and is intended for informational purposes only.
> It does not constitute legal advice. Before taking any action based on this
> information, please consult a licensed Ethiopian lawyer.

## 6. Configuration
No environment variables. To add a language, add its code to `LANGUAGES`,
`LANGUAGE_NAMES_EN`, `DISCLAIMER` and every entry in `UI`, plus `LABELS` in
`web/app.js`. `test_disclaimer_in_every_language` fails if a disclaimer is missing.

## 7. Data, privacy and security
- No personal data is involved.
- The disclaimer wording has legal weight. **Changes need review by the project's
  legal lead.**

## 8. Error handling
Unknown or missing language codes fall back to Amharic. A missing UI string falls
back to English.

## 9. Testing
`test_disclaimer_in_every_language`; `test_ask_filters_hallucinated_citations`
(Amharic disclaimer); `test_analyze_document` (Tigrinya disclaimer);
`test_api_ask` (Afaan Oromo).

## 10. Limitations and next steps
- **The Amharic, Afaan Oromo and Tigrinya strings are first drafts.** They must be
  reviewed by native-speaking lawyers before launch.
- Answer quality in Afaan Oromo and Tigrinya must be measured per language (module 12)
  and labelled "beta" until it meets targets.
- **Somali (Af-Soomaali)** is recommended for Dire Dawa. Add it after evaluation.
- Consider a short plain-language glossary of common legal terms per language.
